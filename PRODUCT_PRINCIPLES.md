# ClienteYA Product Principles

**Version:** 1.0

**Status:** Approved

**Language:** English (Master Version)

**Last Updated:** June 2026

**Founder:** Gerard Henri Steenbergen

---

# Introduction

ClienteYA is not a collection of screens.

ClienteYA is one Commercial Operating System.

Every page exists for one reason.

Every interaction should help entrepreneurs make better commercial decisions.

Nothing is built because it looks impressive.

Everything is built because it creates value.

---

# One Product

Dashboard.

Calendar.

Cliente.

Automations.

Cockpit.

These are not separate products.

They are different perspectives of the same Commercial Operating System.

Every screen must support the others.

Never compete with them.

---

# Dashboard

## Purpose

Answer one question:

> **What should I do today?**

Nothing else.

### Dashboard Must

- Show today's highest-value actions.
- Be understandable within five seconds.
- Reduce decision fatigue.
- Help entrepreneurs start their day with confidence.

### Dashboard Must Never

- Become a CRM.
- Become a reporting tool.
- Show unnecessary information.
- Display future planning.

Action today.

Nothing more.

---

# Calendar

## Purpose

Answer one question:

> **What is coming next?**

### Calendar Must

- Show today's schedule.
- Show tomorrow.
- Show upcoming follow-ups.
- Help entrepreneurs plan ahead.

### Calendar Must Never

- Compete with Dashboard.
- Calculate priorities.
- Replace Automations.

Calendar is planning.

Dashboard is action.

---

# Cliente

## Purpose

Answer one question:

> **What do I know about this relationship?**

### Cliente Must

- Preserve relationship history.
- Preserve commercial memory.
- Explain context.
- Explain previous interactions.
- Explain future opportunities.

### Cliente Must Never

- Become a spreadsheet.
- Become only data.

Relationships first.

Always.

---

# Automations

## Purpose

Answer one question:

> **What deserves my attention?**

### Automations Must

- Prioritize intelligently.
- Explain urgency.
- Explain recommendations.
- Show future workload.

### Automations Must Never

- Duplicate Dashboard.
- Become a task manager.

Automations think.

Dashboard acts.

---

# Cockpit

## Purpose

Answer one question:

> **Why is my business moving in this direction?**

### Cockpit Must

- Show patterns.
- Show forecasts.
- Show commercial intelligence.
- Show opportunities.
- Show risks.
- Help founders make strategic decisions.

### Cockpit Must Never

- Replace Dashboard.
- Replace Cliente.
- Replace Calendar.

Cockpit is strategy.

Not execution.

---

# Artificial Intelligence

AI exists to support entrepreneurs.

Never to impress them.

Every recommendation must be:

- Explainable.
- Reliable.
- Actionable.

If AI cannot improve a decision...

it should remain silent.

---

# Simplicity

Every entrepreneur should understand ClienteYA immediately.

If something needs explanation...

it is probably too complicated.

---

# One Truth

Every screen reads from the same Commercial Operating System.

No duplicated business logic.

No conflicting recommendations.

No contradictory priorities.

One engine.

One truth.

---

# Final Principle

Whenever a new feature is proposed, ask:

**Does this strengthen the entrepreneur?**

If yes,

build it.

If not,

do not build it.

---

> Great products are not defined by the number of features.

> Great products are defined by the clarity of their purpose.
